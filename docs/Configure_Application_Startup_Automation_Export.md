The **Smart Focus Pause & Overdue Catch-Up Rotation** feature has been implemented using **native OS system triggers** for maximum power efficiency and pushed to GitHub.

### ⚡ How it works:

1. **Zero-Power System Event Triggers (No Constant Polling)**:
   - **X11**: Connects via `xprop -spy -root _NET_ACTIVE_WINDOW` using kernel `epoll` socket notifications.
   - **Hyprland**: Subscribes to the native `$XDG_RUNTIME_DIR/hypr/$HYPRLAND_INSTANCE_SIGNATURE/.socket2.sock` event stream.
   - **Sway**: Subscribes to `swaymsg -t subscribe '["window", "workspace"]'` IPC events.

2. **Dormant State While in Applications**:
   - As soon as you focus any application (browser, editor, terminal, game), the rotation timer is cancelled.
   - The process enters sleep on the kernel socket: **0% CPU usage and 0 timer wakeups** while you are working.

3. **Instant Overdue Catch-Up on Return to Desktop**:
   - The moment you minimize windows or switch to the desktop, the OS system trigger wakes the listener.
   - If `elapsed_time >= rotation_interval`, `awall` **immediately changes the wallpaper** and resets the timer cycle.
   - If `elapsed_time < rotation_interval`, it arms a single timer for the exact remaining duration.

4. **GTK4 Settings & Configuration**:
   - Added a **"Smart Pause on Active Application"** toggle under *Preferences -> Rotation Schedule* in the GTK4 GUI.
